● Plan: WSL 2 NAT port forwarding                                               
                                                                                
  flowchart TD                                                                  
      A[Phone port 7777] --> B[Windows Wi-Fi IP]                                
      B --> C[Port proxy]                                                       
      C --> D[WSL port 7777]                                                    
      D --> E[Tau remote]                                                       
                                                                                
  1. Get Windows Wi-Fi address                                                  
                                                                                
  In PowerShell:                                                                
                                                                                
  $wifi = (Get-NetIPAddress -InterfaceAlias "Wi-Fi" -AddressFamily IPv4 |       
    Where-Object PrefixOrigin -ne "WellKnown").IPAddress                        
                                                                                
  $wifi                                                                         
                                                                                
  Example: 192.168.1.50.                                                        
                                                                                
  2. Get WSL address                                                            
                                                                                
  $wsl = (wsl hostname -I).Trim().Split(' ')[0]                                 
  $wsl                                                                          
                                                                                
  Example: 172.28.64.10.                                                        
                                                                                
  3. Confirm port 7777 is free inside WSL                                       
                                                                                
  wsl sh -lc "ss -lnt | grep ':7777 '"                                          
                                                                                
  No output => available. Tau otherwise selects another port, breaking this     
  fixed forward.                                                                
                                                                                
  4. Add Windows port proxy                                                     
                                                                                
  Open PowerShell as Administrator:                                             
                                                                                
  netsh interface portproxy add v4tov4 `                                        
    listenaddress=$wifi `                                                       
    listenport=7777 `                                                           
    connectaddress=$wsl `                                                       
    connectport=7777                                                            
                                                                                
  This forwards $wifi:7777 to WSL $wsl:7777.                                    
                                                                                
  5. Allow TCP 7777 through Windows Firewall                                    
                                                                                
  Still elevated:                                                               
                                                                                
  New-NetFirewallRule `                                                         
    -Name "Tau-Remote-7777" `                                                   
    -DisplayName "Tau Remote TCP 7777" `                                        
    -Direction Inbound `                                                        
    -Protocol TCP `                                                             
    -LocalAddress $wifi `                                                       
    -LocalPort 7777 `                                                           
    -Action Allow `                                                             
    -Profile Private                                                            
                                                                                
  Ensure the Wi-Fi network profile is Private:                                  
                                                                                
  Get-NetConnectionProfile -InterfaceAlias "Wi-Fi"                              
                                                                                
  6. Verify forwarding                                                          
                                                                                
  netsh interface portproxy show v4tov4                                         
  Get-NetFirewallRule -Name "Tau-Remote-7777"                                   
                                                                                
  7. Start Tau inside WSL                                                       
                                                                                
  TAU_REMOTE_HOST=192.168.1.50 tau                                              
                                                                                
  Replace 192.168.1.50 with $wifi, then inside Tau:                             
                                                                                
  /remote local                                                                 
                                                                                
  Tau advertises:                                                               
                                                                                
  http://192.168.1.50:7777/#<token>                                             
                                                                                
  8. Test from another Wi-Fi device                                             
                                                                                
  Open the generated URL or scan Tau’s QR code. Both devices must use the same  
  LAN.                                                                          
                                                                                
  9. Recreate after address changes                                             
                                                                                
  WSL and Wi-Fi addresses may change after restart, reconnect, or router DHCP   
  renewal. Remove the old proxy:                                                
                                                                                
  netsh interface portproxy delete v4tov4 `                                     
    listenaddress=<OLD-WIFI-IP> `                                               
    listenport=7777                                                             
                                                                                
  Then repeat steps 1–4. Update the firewall rule if the Wi-Fi address changed: 
                                                                                
  Set-NetFirewallRule -Name "Tau-Remote-7777" -LocalAddress $wifi               
                                                                                
  10. Rollback                                                                  
                                                                                
  Elevated PowerShell:                                                          
                                                                                
  netsh interface portproxy delete v4tov4 `                                     
    listenaddress=$wifi `                                                       
    listenport=7777                                                             
                                                                                
  Remove-NetFirewallRule -Name "Tau-Remote-7777"                                
                                                                                
  Inside Tau:                                                                   
                                                                                
  /remote off
